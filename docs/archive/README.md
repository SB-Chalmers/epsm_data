# Archived study compatibility

On 14 October 2026, the maintainer retired named legacy studies and their
compatibility routes. Generic study setup, parametric and sensitivity designs,
renovation search, and local/Vera execution remain active in Workflows.

[The dated archive](2026-10-14/src/epsm_data/cohorts.py) preserves Data's former
cohort-inference forwarding module byte for byte. Its
[manifest](2026-10-14/manifest.json) records the source revision and SHA-256.
It is outside the installed package and has no compatibility or reproduction
commitment. Decisions about reuse can be made later.

Current construction values and source evidence remain in Data. Previously
transferred study evidence retains its recorded location in
`epsm_studies/imports/epsm_data_harmonisation`; the Studies archive index records
that historical material.
