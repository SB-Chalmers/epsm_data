2.2 W/(m²K). Package development version: 0.3.0.dev1. The seven-role v1.3 contract,

from 8/12 to 9/12 and MAE from 18.138 to 15.011 kWh/(m² year). The joint candidate

must not be attributed to this database update. All properties were previously
examined, renovation state was unknown, and no independent validation exists.

measured original-construction product. The historical 2.8 reference is retained
in the claim and prior catalogue. Archived extraction reviews remain unchanged.
